聲學預處理參數

高通低頻濾波頻率
Hz

消除教室空調低溫嗡鳴、講台碰撞與呼吸噴麥。男低音講者建議 80Hz 保持飽滿厚度；一般教室建議 100Hz；過高可能削弱男聲基頻。

EBU R128 音量廣播級正規化
LUFS

平衡遠近音量落差，消除突發爆音。-19 LUFS 是語音播客與教學錄音最舒適之標準響度。

頻譜動態降噪衰減量
dB

以頻譜減算法消除固定背景底噪。設為 0 代表關閉；錄音環境安靜建議維持 0，避免產生水聲失真。

VAD 靜音停頓判定門檻
dB

低於此分貝數即視為講者句末停頓。安靜錄音環境可設 -45dB，吵雜環境建議調整至 -35dB。

DeepFilterNet3 深度降噪

分離翻書與鍵盤聲，嘈雜環境推薦啟用。

WPE 聲學去殘響

消除挑高大講堂產生的牆面反射回音。

斷網與額度耗盡備援通道 (Fallback)

遭遇網路中斷或 API 429 配額用盡時，無感切換至本機 RTX 4060 GPU 進行離線辨識。

分段整理字元數 (Chunk Characters)
字

文稿整理分段長度。嚴格比對輸出與輸入字數比例（0.80~1.20），若低於門檻自動攔截重試。

重點總結思考配額 (Thinking Budget)
Token

賦予模型在產出重點總結前進行鏈式推演與考點梳理的 Token 配額。0 代表關閉思考；1024 代表深度提煉公式與題型。
