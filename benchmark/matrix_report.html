# 【核心概念與定義】
- **離散數學 (Discrete Mathematics)**：研究數學結構中可數、離散且非連續變化的數學分支，為計算機科學的理論基礎。
- **圖論 (Graph Theory)**：數學的一個分支，研究由頂點（Vertices）與邊（Edges）組成的圖形結構及其性質。
- **一筆畫問題 (Eulerian Problem / Eulerian Path & Circuit)**：探討在一個圖中，是否能不重複地走過每一條「邊」一次，最終走完全部的路徑。
- **暴力法 (Brute Force)**：最直觀的解題策略，透過窮舉所有可能的狀態或路徑來尋找解答。
- **歸納與推廣 (Induction and Generalization)**：從具體案例中萃取共同特徵，將局部觀察提升為普遍適用之數學規律的能力。

# 【方法流程 / 公式推導 / 演算法架構】
面對未知或複雜的離散數學與演算法問題時，推薦的思考與求解三步驟：
1. **動手實作與具象化（Hands-on & Visualization）**：拒絕過度依賴工具或 AI，親自拿筆繪圖、推導，建立直覺。
2. **暴力窮舉測試（Brute Force）**：先利用最基本、最直覺的邏輯去嘗試所有可能路徑，確認問題邊界與限制。
3. **特徵歸納與模型化（Generalization & Modeling）**：觀察並歸納成功或失敗的特性（例如：點的度數/Degree），將其轉換為抽象數學模型（如圖論中的歐拉定理），以擴大解釋範圍。
